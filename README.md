# ⚡ NestJS-ASTRO Fullstack Portal

> Modern fullstack helpdesk ticket portal combining a robust **NestJS + MySQL (Drizzle ORM)** backend with a **Pure Astro (Zero-JS overhead)** retro Y2K neobrutalist frontend.

---

## 📁 Repository Structure

```text
NestJS-ASTRO/
├── backend/                  # 🛡️ NestJS REST API & MySQL Database
│   ├── src/                  # Controllers, Services, DTOs, Guards, Database Module
│   ├── drizzle/              # SQL migrations generated by Drizzle Kit
│   ├── drizzle.config.ts     # Drizzle Kit CLI configuration
│   ├── Hosting.md            # Complete cPanel Shared Hosting deployment guide
│   ├── app.js                # Phusion Passenger cPanel entry point
│   ├── .env                  # Backend database & port credentials
│   └── package.json          # Backend dependencies (@nestjs, drizzle-orm, mysql2)
│
├── frontend/                 # 🚀 Pure Astro Lightweight Frontend
│   ├── src/
│   │   ├── pages/            # Server-rendered pages (index.astro)
│   │   ├── components/       # Retro OS window cards (StatsGrid, TicketCard)
│   │   ├── styles/           # Neobrutalist pastel grid CSS system
│   │   └── types/            # TypeScript API types
│   ├── .env                  # PUBLIC_API_URL configuration
│   └── package.json          # Pure Astro 5 dependency (Zero-JS runtime overhead)
│
├── package.json              # Monorepo root scripts
└── README.md
```

## 🚀 Quick Start (Local Development)

### ১. ডিপেন্ডেন্সি ইনস্টল (Install Dependencies)

```bash
# Backend dependencies
cd backend && npm install

# Frontend dependencies
cd ../frontend && npm install
```

### ২. সার্ভার রান করা (Run Servers)

রুট ডিরেক্টরি থেকে সরাসরি কমান্ড চালাতে পারেন:

```bash
# ১. NestJS ব্যাকএন্ড চালু করতে (Port 3000):
npm run dev:backend

# ২. Astro ফ্রন্টএন্ড চালু করতে (Port 4321):
npm run dev:frontend
```

ব্রাউজারে ভিজিট করুন: **`http://localhost:4321`**

## 🛠️ Root Monorepo Scripts

রুট ডিরেক্টরি থেকে সহজেই উভয় প্রজেক্ট কন্ট্রোল করতে পারবেন:

| স্ক্রিপ্ট | বিবরণ |
| :--- | :--- |
| `npm run dev:backend` | NestJS ব্যাকএন্ড ওয়াচ মোডে রান করে (`localhost:3000`) |
| `npm run dev:frontend` | Astro ফ্রন্টএন্ড ডেভ মোডে রান করে (`localhost:4321`) |
| `npm run build` | ব্যাকএন্ড এবং ফ্রন্টএন্ড দুটোই একসাথে প্রোডাকশন বিল্ড করে |
| `npm run test:backend` | ব্যাকএন্ডের Vitest ইউনিট টেস্টগুলো চালায় |
| `npm run lint:backend` | ব্যাকএন্ডের oxlint লিন্টার চালায় |
| `npm run db:migrate` | MySQL ডাটাবেজে Drizzle মাইগ্রেশন রান করে |
| `npm run db:studio` | ডাটাবেজ ভিউয়ারের জন্য Drizzle Studio ওপেন করে |

## 🎨 UI/UX থিম ও আর্কিটেকচার

- **ডিজাইন স্টাইল:** Y2K Retro Neobrutalism (Web95 / Retro OS Window Aesthetic).
- **Astro Power:** Zero client JS runtime overhead — পেজের সমস্ত ডেটা সার্ভার-সাইড রেন্ডার হয়।
- **ব্রাউজার নেটিভ মোডাল:** থার্ড পার্টি ভারী প্লাগইন ছাড়া ব্রাউজারের নেটিভ `<dialog>` ব্যবহার করে তৈরি।
- **লাইভ ডিপ্লয়মেন্ট:** cPanel MySQL এবং LiteSpeed-এ সফলভাবে পরীক্ষিত ও ডিপ্লয়ড।
